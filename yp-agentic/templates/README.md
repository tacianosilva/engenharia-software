# Templates de Artefatos — YP-Agentic

Esta pasta contém os modelos oficiais para a elaboração dos artefatos de software desenvolvidos sob o processo **YP-Agentic**.

## Lista de Templates Disponíveis

1. `doc-visao.md` — Documento de Visão
2. `prd.md` — Product Requirements Document (PRD)
3. `doc-userstories.md` — Lista de User Stories (Backlog estruturado por entidade)
4. `esp-userstories.md` — Especificação de User Stories (BDD, Mermaid e Figma)
5. `plano-geral-testes.md` — Plano Geral de Testes de Software
6. `plano-release.md` — Plano de Release
7. `plano-iteracao.md` — Plano de Iteração (Timebox de 2 semanas)
8. `plano-teste-iteracao.md` — Plano de Teste da Iteração
9. `atas-reuniao.md` — Ata de Reunião
10. `relatorio-testes.md` — Relatório de Testes da Iteração
11. `termo-abertura.md` — Termo de Abertura do Projeto (TAP)
12. `doc-modelos.md` — Documento de Modelos (Conceitual, DER e Dicionário de Dados)
13. `doc-arquitetura.md` — Projeto Arquitetural (HLD, componentes, tecnologias e ADRs)
14. `doc-agentes.md` — Documento de Agentes de IA (Governança e papéis)
15. `termo-encerramento.md` — Termo de Encerramento do Projeto (TEP)
16. `DESIGN.md` — Design System (Transversal: identidade visual e componentes de interface)
