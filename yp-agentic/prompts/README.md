# Prompts de Engenharia de Software — YP-Agentic

Esta pasta contém as instruções e prompts padronizados para guiar agentes de IA na geração e refinamento dos artefatos de software do processo **YP-Agentic**.

## Lista de Prompts

1. `doc-visao.md` — Prompt para geração do Documento de Visão
2. `prd.md` — Prompt para elaboração do PRD (Product Requirements Document)
3. `doc-userstories.md` — Prompt para criação do Backlog de Histórias de Usuário
4. `esp-userstories.md` — Prompt para detalhamento e especificação BDD de Histórias de Usuário
5. `plano-geral-testes.md` — Prompt para elaboração do Plano Geral de Testes
6. `plano-release.md` — Prompt para elaboração do Plano de Release
7. `plano-iteracao.md` — Prompt para elaboração do Plano de Iteração
8. `plano-teste-iteracao.md` — Prompt para elaboração do Plano de Teste da Iteração
9. `atas-reuniao.md` — Prompt para elaboração de Atas de Reunião
10. `relatorio-testes.md` — Prompt para elaboração do Relatório de Testes
11. `termo-abertura.md` — Prompt para elaboração do Termo de Abertura do Projeto (TAP)
12. `doc-modelos.md` — Prompt para elaboração de diagramas conceituais e dados (Mermaid)
13. `doc-arquitetura.md` — Prompt para decisões arquiteturais e visão C4/componentes
14. `doc-agentes.md` — Prompt para configuração e definição de agentes de IA do projeto
15. `termo-encerramento.md` — Prompt para elaboração do Termo de Encerramento do Projeto (TEP)
16. `DESIGN.md` — Prompt para elaboração do Design System (a partir de Figma, CSS e imagens)
